# 第六轮质量打磨：压缩中的关系与条件保真

日期：2026-09-11

评分复核说明：初次盲评把紧邻“读书会改至周日”的“无法参加”误判为面向所有人的确认要求。另一个同项目任务只读复核后，P05 第三项按语义等价修正；原始输出、冻结标准、盲评顺序和偏好均未改。修订发生在揭盲后，属于模型辅助复核，不是独立人工盲评。

## 问题与修订

上一轮 Promptfoo 原生三方 pilot 的 W04 中，无 Skill、`prose-polish` 0.1.1 和 Humanizer 都在 60 字压缩时省略了原定周六；本仓库 Skill 还把“周日来不了”泛化为“无法参加”。这说明“保留日期和范围”的一般规则不足以稳定保住两个值之间的变化关系，以及条件限定与动作之间的绑定。

本轮先把 0.1.1 完整包冻结为本地旧版快照，再把 `prose-polish` 升至 0.1.2。正文只增加一项窄规则：

- 压缩时保留原定值、当前值以及待定或取消状态之间的关系；
- 把适用对象、多个同时成立的条件、动作和期限绑定；
- 空间不足时先删套话与重复，不用扩大适用范围换取简短；
- 用户明确声明旧值错误或作废时，仍按更正只保留有效新值。

当前包 SHA-256 为 `e7c4efa2e874dc91a06d35c5144060944e25af6654cbb1e6560597c7aae7a932`；冻结的 0.1.1 为 `9c3315b74cbebfa110ec08f4478d99663e335e0915023514887e7fa06190d9a1`。

## 评测设计

使用 Promptfoo 0.123.0 与 Codex SDK，在独立 Git 根、用户目录和只读沙箱中比较：

- `baseline`：无 Skill；
- `old`：显式调用冻结的 0.1.1；
- `current`：显式调用 0.1.2。

项目级 Skill 发现沿用已通过的 `promptfoo-native-discovery-canary-06`。评测材料全部为合成文本，生成时看不到评分标准；模型辅助评阅先对匿名候选逐项保存布尔判断，再由计分器揭盲；揭盲后的独立只读复核修正了 P05 一项语义判定，并保留修订前后的评分产物及哈希。所有正式结果行均完整，没有 provider 错误、MCP 或网页搜索轨迹。

比较集包含六题。P01 到 P04 覆盖改期、合取条件、状态演进和英文通知；P05 精确复现上一轮失败；P06 检查新版会不会错误保留用户已声明作废的旧值。

## 一般化 pilot

P01 到 P04 每臂各执行一次，共 12 次调用：

| 实验臂 | 标准通过 | 完整通过输出 | 盲评偏好 |
| --- | ---: | ---: | ---: |
| 无 Skill | 15/16 | 3/4 | 3 |
| 0.1.1 | 16/16 | 4/4 | 0 |
| 0.1.2 | 16/16 | 4/4 | 1 |

结果 SHA-256 为 `6f61fc2f594985102718d79115f4b33efa98479989972d556744472b731278f8`。新版与旧版在这四题没有通过率差异；无 Skill 虽漏掉 P03 的“30人是原计划”，但在三题获得文风偏好。该结果不支持声称新版普遍写得更好。

## 定向三次回归

P05 和 P06 每臂各执行三次，共 18 次调用：

| 实验臂 | P05 改期保真 | P06 作废旧值 | 合计 | 完整通过输出 | 盲评偏好 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无 Skill | 9/12 | 12/12 | 21/24 | 3/6 | 0 |
| 0.1.1 | 11/12 | 12/12 | 23/24 | 5/6 | 1 |
| 0.1.2 | 12/12 | 12/12 | 24/24 | 6/6 | 2 |

P05 上，新版三次都保留“本周六改周日”，旧版两次完整通过，基线没有完整通过；三组的私信动作都可由紧邻语境解释为只面向无法参加周日场次的人，明确写出“周日”仍更清楚，但不是冻结标准要求的唯一合格表达。P06 上三组输出完全相同，均把 12 名更正为 15 名且没有保留作废旧值。本轮没有观察到新规则导致的过度保留副作用。

定向回归结果 SHA-256 为 `eac1609582c5e32a0d7620b6bf8ea5f6e3ceb5017816a794e269b64cdf4e4323`。相应调用的总 token 为基线 57,430、旧版 64,758、新版 65,621；估算成本分别为 0.0888784、0.0930960、0.1044424。

## 结论与边界

这组证据支持 0.1.2 在已知短通知中更稳定地保留原定与改后日期关系，而且没有在明确更正场景中保留作废旧值；条件限定本身在语义复核后没有形成三组差异。它仍是两题上的定向三次回归，加上四题各一次的一般化 pilot；评阅者是模型而非独立人工，调用方式是显式 Skill，尚未测试自然语言自动路由、其他模型、其他宿主或真实材料。因此 `prose-polish` 继续保持 `experimental`，不标记为 `verified`。

活动用例新增两项，`prose-polish` 共 9 项，全仓当前共 96 项。仓库结构校验与全量单测通过；Windows 环境仍有一项符号链接测试因缺少创建权限而跳过。
