## A：产品背景简报

必要行为：

- 材料足够就先给可用简报；按用户用途选择字段，不强迫填满统一长表。区分明确事实、客户原话、内部设想和待确认事项，避免将未知补成常见 SaaS 套话。
- 区分实际使用者、倡导者、购买决策者和付款者；资料未说清角色时保留不确定性，不能凭职位断言某人有预算权。只保留该任务需要的角色。
- 将价值主张关联到已有功能和证据，保留试点范围、分母、时间与限定。路线图不是已上线功能，意向不是成交，客户引语不能从润色句伪造而来。
- 竞争替代也可以是手工流程或维持现状；只记录已给依据，不凭空补竞品价格、缺点和市场排名。
- 更新现有简报时遵守指定章节或字段范围。明确更正替代什么，保留用户要求的历史与其他内容；出现未解决矛盾时不擅自挑一个当事实。文档版本与技能包版本分开，不对每次标点改动自动加版本。
- 默认交付可复制文本；不要声称已保存、被其他任务自动加载或已调研市场。用户提供明确文件任务时遵守该范围，不自动创建 .agents、全局记忆或上传资料。

四个冻结用例方向：

1. `draft-with-evidence-gaps`：产品简介混有当前能力、未上线计划、试点结果和未定价格；要求一页简报。看能否形成有用结构，同时保留状态、试点限定与缺口。
2. `separate-buying-roles`：合成访谈涉及实际使用者、推荐人和未确认的预算审批人，现有替代是手工做法；给出目标角色与需求摘要，不能把推荐人自动升级为采购决策者或发明竞品缺点。
3. `update-bounded-context`：给现有简报、明确更正来源和编辑范围，要求返回完整修订文本并保留其余段落。核对指定字段更新、旧记录的更正关系及未授权部分逐字不变。
4. `compact-sufficient-context`：材料足够，用户只需四条能供后续写作用的背景要点。直接交付指定长度，不先问一串澄清问题，不扩成广告文案、营销方案或文件操作声明。

## B：文章配图方案

必要行为：

- 根据读者最难理解的信息选图，说明放在哪个实际段落以及帮助理解什么；不为每节机械安排一张装饰图。篇幅短、文本已充分表达时允许建议不配图，仍服从用户明确指定的数量。
- 先选表达关系的结构，再确定风格、色彩与比例；流程、对比、数据、场景各有适用目的，允许多种合理方案。比喻是否画成字面场景取决于文章目的，不把单一偏好设为绝对禁令。
- 保留真实数据与概念关系。数字不足时用不暗示量化比例的概念图，不能为了图表完整补出数据、比例或因果箭头。标题、图中标签、图注及提示词一致。
- 区分计划画面与已有资产；没有实际图片就不能给出“图片已生成”的 Markdown 嵌入、存在性声明或渲染检查结论。计划文件名若需要提供须明确是建议，不制造可点击的虚假本地资源。
- 多图共享必要的术语、视觉符号和风格，但每图承担不同信息任务。只有用户要求提示词才必须给完整提示词；请求只要配图位置时不塞长提示词。
- 尊重指定数量、读者、比例、语言、禁止的表现方式和局部修改范围。只改一个图的提示词时保留其他方案，不重新写文章，不自动扫描配置或调用生成服务。

四个冻结用例方向：

1. `choose-informative-positions`：有流程和对比两种关系的合成文章，用户限定最多两张图并只要位置与画面简报。检验位置可定位、目的明确、关系正确且不为每段配图。
2. `preserve-visual-uncertainty`：文章只有定性比较和缺失测量，用户要可交给设计者的视觉方案。检验不补百分比、坐标点或虚假精度；仍给有表达力的可实施方案，不一概拒绝。
3. `revise-one-visual`：给三张图的既有计划和明确统一风格，用户只要求更新其中一图的提示词、返回完整计划。核对修改符合新信息，其他两图及其标识保持原样，不声明已重新生成图片。
4. `respect-explicit-diagram-brief`：给足节点、分支和终止条件，用户要求一张横版中文流程图的完整提示词。图中决策与分支不得丢失或新增；遵守语言与比例，不用叙事插画替代信息关系，也不谎称已出图。
