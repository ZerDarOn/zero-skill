# 第二十三轮质量打磨：Obsidian 窄编辑制品保真

本轮用六个未参与 `obsidian-note-edit` 0.1.0 编写的新合成任务，比较无 Skill、当前本地 Skill，以及 Obsidian Skills 固定提交 `a1dc48e68138490d522c04cbf5822214c6eb1202` 的 `obsidian-markdown`。协议先在提交 `4f0581582d6132b30b808d929a57a76eaf37dfe2` 冻结；三臂使用相同的 `gpt-5.6-sol`、`medium`、只读隔离环境和任务正文，两个 Skill 臂采用项目级显式调用。每题每臂重复三次，共 54 份输出、18 个三候选匿名评阅项和 216 个逐项布尔判断。

## 结果

三臂的 54 份提交都是可解析的固定两字段 JSON，`note` 全部与冻结期望制品逐字一致，只使用协议允许的单个末尾 LF 宽容。无 Skill 与当前 0.1.0 都是 `72/72`、`18/18` 份完整；上游是 `71/72`、`17/18` 份完整。18 项均无唯一偏好：17 项三方并列，1 项 baseline 与 ours 并列最佳。

上游唯一扣分发生在 `retarget-existing-not-planned-note` 的第二次重复：Markdown 制品本身完全正确，但 `message` 只泛称完成链接更新、其他内容未改，没有按任务要求明确区分“已确认重命名”和“季度复盘仍是计划目标”。揭盲后独立复核确认该判定符合冻结标准，其他评分无需校准。

| 机制 | 制品核心失败（无 Skill / 当前包 / 上游） | 完整输出 | 候选门槛 |
| --- | --- | --- | --- |
| 受保护字节 | `0/6 / 0/6 / 0/6` | `6/6 / 6/6 / 6/6` | 未触发 |
| 格式范围 | `0/6 / 0/6 / 0/6` | `6/6 / 6/6 / 6/6` | 未触发 |
| 目标状态 | `0/6 / 0/6 / 0/6` | `6/6 / 6/6 / 5/6` | 未触发 |

冻结门槛只比较 ours 与 baseline：同一机制的两道题都必须出现当前包至少 `2/3` 次第 1 项制品失败，且 baseline 在每题均不超过 `1/3`。六题两臂的制品失败全部是 `0/3`，因此不打开 0.1.1 候选设计。当前 Skill、版本、`experimental` 状态和空 `evidence` 均保持不变；六题加入活动回归，`obsidian-note-edit` 从 4 例增至 10 例，全仓从 132 例增至 138 例。

## 质量判断

本轮证明三种条件都能在这些窄编辑任务中生成精确制品，也没有发现当前 Skill 的制品保真退化。baseline 已经全对，当前 Skill 没有可测的准确率或偏好增益，因此没有证据支持继续增加指令。上游的一次说明项失败只反映这份样本中的边界沟通差异，不能据此形成一般排名。

代价差异明显。当前包相对 baseline 的总 token 增加 87.3%，记录成本增加 116.9%，中位延迟增加 67.7%；上游相对 baseline 分别增加 52.2%、107.8% 和 38.6%。当前包相对上游的总 token 增加 23.0%、成本增加 4.4%、中位延迟增加 21.0%。这些数字只描述本轮相同配置，不能外推为通用成本规律。

## 证据完整性

第 1 项制品标准在揭盲前由确定性脚本填入匿名表单，脚本验证了 packet、form、cases 和运行哈希，并拒绝身份字段与越界 cases 路径。语义评阅者只读取匿名候选包和预填表单；第 2–4 项及偏好完成后才揭盲。

原始盲审文件误把评阅模型自报为 `gpt-6-astra/high`，与任务创建时实际分配的 `gpt-5.6-sol/medium` 不一致。原件和第一次计分结果均保留；同一评阅者另写元数据更正版。机器报告证明两份文件的全部 reviews、逐项布尔、notes 和偏好完全相同，两份计分结果除 reviewer metadata 与对应 review hash 外也相同。这是揭盲后的元数据更正，不是重新评阅或改分。

自包含机器报告绑定冻结提交、协议与准备文件哈希、十三份运行产物哈希、四份独立复核哈希、当前与上游包指纹、上游 provenance、54 份完整输出、冻结期望制品、机械检查、逐项评阅、偏好、聚合分数、门槛和决定。测试会从报告内嵌输出与已提交的冻结来源复算制品精确性、输出与期望哈希、三臂总分、逐题核心失败、门槛、全部效率差异和证据投影，并直接验证四份已提交复核、当前包、上游许可证与活动回归。13份原始运行产物由 Git 忽略；本地 run 目录存在时另行逐文件核对，新的 clone 只能核验报告内嵌证据，不能独立重建这些原始文件。

## 限制

本轮只有六个合成窄编辑任务、单一模型、单一推理等级和每臂三次重复。评阅者都是模型辅助子代理，并非独立人类。正式运行返回文本制品，没有编辑真实 vault，也没有验证文件系统、Obsidian 渲染、链接扫描、插件集成或隐式路由；运行记录也没有逐会话 Skill 调用轨迹。因此结果不能支持 `verified` 状态、真实应用验收或普遍优越性结论。
