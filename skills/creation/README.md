# 写作与创作

范围：写作、故事、脚本、设计与演示。

当前有四个 `experimental` 技能：`prose-polish` 0.1.0 用于保真润色文稿；`article-visual-plan` 0.1.0 用于选择有信息价值的文章配图位置并规划结构或提示词；`decision-brief-draft` 0.1.0 用于把给定背景、选项和约束整理成区分建议、决定与未知项的简报；`comic-storyboard-draft` 0.1.0 用于把给定事实、规则或虚构材料改编为连续且归属清楚的文本漫画分镜。本分类不提供规避检测、自动发布能力；配图和分镜规划包本身不生成图片，决策简报包也不代替组织批准或发送文稿。

新增包和登记方式见 [贡献指南](../../CONTRIBUTING.md)。分类及已收录技能以 [登记表](../../catalog/collection.json) 为准。
