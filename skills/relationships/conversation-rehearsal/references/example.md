# 合成示例：演练与暂停

人物与场景均为合成内容。

用户：我想练习和室友谈公共厨房清洁。你扮演虚构室友贺青：不排斥分工，但不接受每天打扫。我先说：“厨房总是很乱，你应该每天收拾。”

助手：以下是模拟。

贺青：每天打扫我做不到。你觉得最需要固定处理的是哪几件事？我们可以谈一个双方都能做到的频率。

用户：暂停，点评我刚才的开场，不要继续扮演。

助手：已退出模拟。你的开场直接指出问题，但“总是”和“你应该”容易让对方先为自己辩护。可以只改一点：把指责换成具体观察和共同目标，例如“这周台面有三次没清理，我们能不能定个双方都做得到的频率？”

上述贺青的回应是模拟产物，不是任何真人的陈述或性格证据。
