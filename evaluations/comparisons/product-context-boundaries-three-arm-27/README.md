# 产品背景复杂边界三臂前向比较

`product-context-brief` 0.1.0 已有七个活动合成用例，早期完整复跑为 `7/7`，但新增三题的无 Skill 组也全部通过，且评分不是独立盲评。本轮比较无 Skill、当前本地技能与固定的 `marketingskills/product-marketing` 2.1.0，使用六个未参与当前技能编写的新表面检查更复杂的来源范围、角色权限和有界更新。

## 固定设计

三臂使用同一个 `gpt-5.6-sol`、medium、只读隔离配置、公共提示与任务正文。两个 Skill 臂采用项目级显式调用。每题每臂重复三次，共 `6 × 3 × 3 = 54` 份输出、18 个三候选匿名评阅项和 216 个布尔判断。失败保留且不重试。

六题按三个机制各两题组织：

- `publication-scope`：总体正式开放与局部故障同时成立；模糊的退役横幅不能抹平新账户停售与既有合同账户限期可用的范围。
- `stakeholder-authority`：金额阈值限制当前审批权；隐私否决、建议、采购批准和付款执行是不同角色。
- `bounded-evidence-update`：单位与结果不同的研究不能拼接分母；只修改获准章节并逐字保留已审批文档的其他部分。

每题四项硬标准，前三项是核心标准。候选门槛要求同一机制的两题都出现当前 Skill 至少 `2/3` 次核心失败，同时 baseline 每题最多 `1/3` 次核心失败，且 54 份输出全部有效。满足门槛只允许打开最小候选设计，不直接改 Skill、升版或改变 catalog。upstream 提供外部参照，不进入本地回归门槛。

匿名评阅按语义满足程度判断，不要求逐字复述；只有明确要求逐字保留的受保护文档片段按字节核对。评阅只能使用冻结题面支持的事实与预先写入的硬标准，不得揭盲后增加要求。偏好与逐项硬标准分开记录，偏好不改变布尔判断。

## 上游边界

上游固定在 `coreyhaines31/marketingskills@5b2c0007766c6a1cf1d53fd8fc73e979e0821022` 的 `product-marketing` 2.1.0，许可证为 MIT。该上游擅长完整的营销上下文模板、协作采集、版本与变更记录；本地技能更强调给定材料的证据层次、局部更新和无写盘交付。本轮只比较两者共同覆盖的一次性文本整理子任务，公共提示统一跳过查文件、提问、保存和同步，因此不能外推为完整产品营销工作流排名。固定包只含入口文本和附带许可证，不安装或执行上游脚本。

本轮只测试合成、单轮、中文、显式调用和文本返回，不验证真实发布系统、账户权限、文档写入、多人协作、隐式路由或营销效果。
