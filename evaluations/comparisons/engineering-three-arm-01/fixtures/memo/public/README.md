# 异步查询缓存
Python 3.11+，仅标准库。AsyncMemo.get(key, loader) 合并同一key的异步查询，并缓存成功结果；不同key独立。
loader是一个零参数异步函数。调用者取消自己的等待，不能取消底层共享查询，即使它是唯一等待者。失败或底层自身取消的查询不能永久占住缓存，后续调用应能重试。invalidate(key)移除当前缓存但不取消已经开始的查询；老查询完成或失败不得破坏同key的新查询。已发出的调用仍应获得自己原来等待的结果/错误。
最近用户报告：取消一个查询窗口后，另一个窗口也收到了取消；偶发一次后端错误后一直失败，重启才恢复。不要增加自动重试或第三方依赖。公开复现见test_public.py。
