# Relationship nested source forward 10

这是 relationship-review 0.1.4 的独立前向诊断，针对第十六轮仍未解决的嵌套来源压平。它不预设继续升版：先检查0.1.4能否在表面不同的新材料里区分当前说话者、直接转述者、更早来源与原始说话人，同时保留不确定程度。

三个新合成任务覆盖项目群中的多跳排期传话、发生更正的多跳值班传话，以及有限日历记录与多跳候选更新并存。第四题是直接权威更新控制，检查来源规则不会让已经由负责人明确确认的安排重新变成传闻或待核实状态。

无Skill与0.1.4使用相同的 gpt-5.6-sol medium、任务正文和只读隔离环境。Skill臂采用项目级显式调用；硬标准不进入生成提示。四题、两臂各重复三次，共24个独立输出，失败不重试。

正式运行前须由另一个同项目任务检查：多跳链条是否能从题面唯一解析、群消息中保留每一跳是否自然且必要、更正题是否使用最新有效状态、直接来源控制是否会误惩合理回复，以及标准是否只判断可观察输出。冻结后先提交再运行。

若0.1.4稳定保留多跳来源且直接来源控制不退化，则记录通过而不修改Skill。只有跨任务稳定出现同一压平机制时，才设计更抽象的候选规则和新的前向题；不得从本批答案反写固定模板。

本实验不测试隐式发现，不新增第三方上游，也不使用真实聊天、账户或人物材料。模型盲评不是独立人工关系专家评审。

准备命令：

    python evaluations/promptfoo/prepare_skill_comparison.py --spec evaluations/comparisons/relationship-nested-source-forward-10/promptfoo.json

运行、汇总与盲评沿用 [evaluations/promptfoo/README.md](../../promptfoo/README.md)。
