# 第八轮质量检查：人物证据分析原生盲测 pilot

日期：2026-09-11

## 范围

本轮没有修改 `person-evidence-analysis` 0.1.2，而是先建立一组未参与其规则编写的合成任务，比较无 Skill 与显式调用当前 Skill。六题覆盖：

- 单次延迟回复是否被升级成轻视；
- 重复转述、条件语境和反证；
- 本人自述与两场实际互动的差异；
- 跨时间变化；
- 模糊指代；
- 三个独立事件已支持有界模式时，能否避免一概拒绝判断。

计划每题重复三次；本轮只执行一次 pilot，共 12 次真实 Codex 调用。模型为 `gpt-5.6-sol`、medium。两组在临时独立 Git 根和用户目录中运行，断网、禁用网页与宿主集成，没有 provider 错误或外部工具轨迹。

## 冻结盲评分

另一个同项目任务只读取匿名 packet 和空白评分表，没有打开映射 key、results、summary 或 prepared 目录。它逐项保存布尔判断后，本任务用既有计分器揭盲。

| 实验臂 | 标准通过 | 完整通过输出 | 盲评偏好 | Token | 估算成本 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无 Skill | 20/24 | 3/6 | 1 | 57,606 | 0.0955120 |
| 本地 Skill | 22/24 | 4/6 | 5 | 66,136 | 0.1109824 |

本地 Skill 比基线多约 14.8% token，估算成本多约 16.2%。这是单次样本，不能解释为稳定成本差异。

最清楚的质量差异出现在 E01：本地 Skill 把火车和信号保留为甲在消息中的自述，并限制推断；基线称其为“客观情况”，没有保留替代解释。E04 中本地 Skill 保留了两次内部演练，基线省略了次数。E02、E03 和 E06 两组均完整通过，说明基线在重复来源、冲突观察和有证据的正向模式上已能完成任务。

E05 是共同失败：甲说“你选一个，我来执行”，两组都只保留“让乙选择”，漏掉甲仍承担执行的承诺。这个遗漏会使“是否把决定推给别人”的证据看起来更单向，值得做下一轮定向测试。

## 评分设计复核

揭盲后复核发现两项冻结标准比用户任务更窄：

- E01 要求显式写出“约六小时”，但用户问的是是否不尊重；两组都保留了预告延迟与到站后完整答复的顺序。
- E04 要求复述“两次”内部演练；若回答保留拒绝、演练、主动演示的时间变化，次数省略不必自动使核心判断失败。

冻结盲分继续保留，不在结果出来后改标准。另做的诊断性核心重算仅把这两类等价表达视为合格，得到无 Skill 22/24、当前 Skill 23/24，完整通过 4/6 对 5/6。它只说明原始 2 分差距中有 1 分来自真正的来源处理差异，不能替代正式盲分。

E05 的“我来执行”不同：这句话直接影响责任是否仍由甲承担，省略会改变待判断关系，因此继续作为有效失败。

## 平衡证据定向复查

为判断 E05 的遗漏是否稳定复现，另建四题，覆盖交给别人选择但自己负责落地、委托分析但保留最终决定、当下拒绝但承诺后续完成，以及只问“谁决定”的简短反例。仍只执行一次，共 8 次调用。

| 实验臂 | 冻结标准通过 | 完整通过输出 | 盲评偏好 | Token | 估算成本 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无 Skill | 12/16 | 1/4 | 1 | 37,314 | 0.0329904 |
| 本地 Skill | 15/16 | 3/4 | 3 | 42,780 | 0.0632256 |

严格分再次夸大了差异：B01 强制复述“甲已列好两个方案”，B03 强制重述明早与周三的具体时间，B04 在用户只问谁决定时仍强制写出“先做B”。这些细节在各题的核心判断中不是必要条件。按运行后冻结的语义校准样本重看，两组均为 16/16、4/4；正式盲分不改，校准分不替代它。

更关键的是，E05 的责任信息遗漏没有复现。B01 和 B02 两组都保留了甲承担最终方案、上线或对客户解释的责任；B03 本地 Skill 更完整，但基线的“随后按承诺完成”也足以表达承诺与兑现。B04 说明简单归属问题不需要强制展开整段责任分析。

因此本轮不修改 `person-evidence-analysis`，不升版本，也不追加为 active 用例。当前最诚实的判断是：Skill 输出在两轮单次 pilot 中更常被偏好，来源与范围表达有一个窄优势，但尚无稳定的核心正确率增益。

## 为什么没有 Nuwa 第三组

仓库固定的 Nuwa 提交 `fe0374687037c4cc51a65c1e0c145afe2981dc69` 用于深度调研并生成可运行的人物或主题 Skill。它不是对用户给定聊天片段做一次有界人物分析。把它放入本题会把任务范围不匹配误写成上游质量差异，所以本轮不纳入实验臂。

后续找到任务匹配、许可证与提交可固定的上游，才增加第三组。当前只支持说本地 Skill 相对无 Skill 出现了一个窄的单次信号。

## 下一步

1. 把 E01 与 E04 的非关键复述要求在下一版比较集里改成语义等价标准，保留本轮原件。
2. 为“交出选择但保留执行责任”准备两个不同场景，再判断 E05 是否是稳定失败。
3. 有稳定失败后才最小修改 Skill、升版本并做旧版／新版回归。
4. 隐式路由继续视为宿主门禁未建立；不拿显式调用替代自动发现证据。
