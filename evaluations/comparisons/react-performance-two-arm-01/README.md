# React 性能审查原生盲测

本比较使用六个未参与 `react-performance-review` 0.1.1 编写的合成任务，比较无 Skill 与显式调用当前包。第一次正式运行冻结的是0.1.1并按每题三次执行；最终又用同一规格冻结0.1.3做每题一次的广覆盖回归。具体版本和包指纹以各次冻结记录与诊断报告为准。冻结标准接受多种保持语义的实现。

题目覆盖 Context value 身份、stale closure、Transition 调度、搜索请求竞态、`useSyncExternalStore` 快照身份和大列表虚拟化。运行前由另一个同项目任务在不读取 Skill 正文和历史结果的条件下复核题面与标准；运行后由同一任务只读取匿名候选和评分表，揭盲前逐项保存判断。

Vercel `react-best-practices` 的固定入口与本任务匹配，但固定提交缺少已核验的独立许可证正文，且入口引用的规则闭包未能在当前宿主完整取得，因此本轮不把残缺副本作为第三臂。目录名和结论中的“两臂”必须保持这一事实。

该比较只评估合成材料下的静态审查输出。没有运行 React 应用、浏览器、Profiler 或无障碍技术；显式调用不证明隐式发现。
