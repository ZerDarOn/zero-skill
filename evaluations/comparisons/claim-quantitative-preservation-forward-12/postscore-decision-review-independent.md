# 第十九轮揭盲后决策独立复核

日期：2026-09-11
复核对象：`claim-evidence-review` 0.1.0 与 `claim-quantitative-preservation-forward-12` 冻结对照

## Findings

### [P1] 本轮没有达到预声明的 0.1.1 候选设计门槛

正式盲评为：baseline `35/36`、`11/12` 完整、2次偏好；0.1.0 为 `34/36`、`10/12` 完整、2次偏好；另有8次持平。0.1.0 的两次失分分别出现在：

- `independent-trials-different-endpoints-r2`：只保留 `75%/65%` 和 `68%/64%`，遗漏原始 `150/200`、`130/200`、`170/250`、`160/250`；
- `regions-with-missing-denominator-r1`：说明南区前期分母缺失，但遗漏仍然已知的“前期11单投诉”。

这两个失分跨两个题型，但每个题型都只出现一次，不满足 README 中“0.1.0在至少两个新题型中重复漏掉”的题型内重复条件。与此同时，`regions-with-missing-denominator-r3` 的 baseline 也遗漏了前期11单，说明该表面并非 Skill 臂独有；本轮 baseline 只少一次失败，在12个输出、每题3次的规模下不足以构成“明显更少”。

**要求：保持0.1.0，本轮不设计0.1.1候选。** 不应在揭盲后把“跨两个题型各一次”重新解释成“至少两个题型中重复”，也不应把一分差改写为稳定退化。

### [P1] 跨轮风险已经扩大，但只能触发新的确认性复测

第十八轮 `shared-data-with-new-analysis` 中，0.1.0 三次有两次漏掉至少一批精确数字，baseline 三次有一次同类遗漏。第十九轮又出现0.1.0在随机试验题遗漏样本分母一次、在缺失分母题遗漏已知计数一次；baseline在缺失分母题也遗漏一次。

按“每个题型的一条定量保真硬标准”计，第十八至十九轮五个相关新题型、每臂15个输出中，0.1.0 共4次遗漏，baseline 共2次遗漏。这个累计观察跨越共享复核、不同试验终点和缺失分母三个表面，已经比第十八轮单题残留更值得关注；但它不是第十九轮预声明的升版判据，而且第十九轮两个0.1.0失分都没有在题型内复现。把跨轮探索性累计直接替代本轮冻结门槛会构成事后改规则。

**要求：把它登记为“跨轮定量保真风险信号”，用新的预注册拓扑确认；不能据此直接修改 Skill。**

### [P2] 原始分子分母标准合理，冻结分不应事后放宽

当前 Skill 明确承诺“保留分母、样本、日期、比较组、否定、概率和不确定性”。本轮 README 又在运行前声明，四题都要求保留会改变结论的核心分子、分母、前后值或终点范围，而不是机械复述无关数字。

在随机试验题中，`75%/65%` 与 `68%/64%` 保留了比例和效应方向，却丢失每组200人与250人的样本规模；样本分母是两项证据范围和信息量的一部分，且两项试验分母不同。冻结标准要求原始分子分母与终点、窗口一起保留，直接对应 Skill 的既有承诺，不是揭盲后新增要求。因此该项严格失败应保留。

在南区题中，前期分母未知使投诉率不可计算，但“前期11单投诉”仍是材料明确提供的定量观察。只写“前期分母缺失”会把“已知分子、未知分母”压成笼统未知，也正是题目要区分的状态。因此0.1.0 r1 与 baseline r3 的严格失败同样合理。

这些标准没有要求日期、作者名或对结论无影响的附带数字，也接受同时给原始计数和等价百分比。**不得因揭盲后发现失败来自 ours 而把百分比追认成完整满足原分子分母标准，或重评既有72个布尔。**

## 决策

**保持 `claim-evidence-review` 0.1.0，不改 Skill、不升版；建议把四个冻结题全部加入活动回归。**

四题都应保留，而不只保留两个失分题：

- `two-queues-shared-audit` 保护“两批独立样本 + 同批复核非第三批”的正向完整输出；
- `regions-with-missing-denominator` 固化“已知分子、未知分母”的部分可知状态；
- `independent-trials-different-endpoints` 固化不同人群、终点、窗口、效应与样本规模；
- `two-bullet-cross-product-summary` 保护严格压缩下仍保留关键数字，同时防止未来修订演变成机械列举或破坏输出形状。

若实施，`claim-evidence-review` 活动用例将从10项增至14项，全仓活动用例将从112项增至116项；这两个数字应在实际写入和集合校验后再作为当前事实发布。本复核没有执行该修改。

## 下一步确认性复测设计

建议先冻结第三组前向协议，再决定是否设计候选：

1. **三个全新表面，每臂五次，共30个输出。** 使用更高重复数降低一次性遗漏对结论的影响。
2. **题型一：相同比例、不同分母。** 两个独立样本比例相同但样本量明显不同，要求保留各自原始分子分母，避免只报百分比后丢失证据规模。
3. **题型二：已知分子、缺失或更正分母。** 至少两组材料处于“分子已知、分母未知/被更正”的不同状态，要求保留已知值、拒绝补造未知值。
4. **题型三：严格短输出下的多证据单元。** 例如严格两句或三格表格，每个证据单元只保留会改变结论的最小定量元组；同时设置一个不应列举次要数字的简洁控制，防止把候选方向推成全量抄录。
5. **预先量化“baseline明显更少”。** 建议只有0.1.0在至少两个新题型中各出现不少于 `2/5` 的核心定量遗漏，且 baseline 在这些同题型中各不超过 `1/5`，才打开0.1.1候选设计；标准必须在运行前冻结。
6. **达到门槛后仍不直接升版。** 先设计一个通用的“按独立证据单元保留最小结论决定元组”候选规则，再用未参与修订的新题做 baseline／0.1.0／候选三臂对照，并完整回归第十八、十九轮十题。

这个设计把“原始分母是否被保留”“已知分子是否被误删”和“简洁输出是否退化”分开判定，能区分真正机制缺口与随机压缩，而不会围绕 `200/250` 或“南区11单”写固定模板。

## 证据边界

- 本结论依据单一模型、`medium`、四个合成题、每臂三次和模型辅助匿名盲评；偏好与一分差都不具统计显著含义。
- 0.1.0 臂配置为项目级显式调用，但 summary 没有 `skillCalls` 遥测，不能单独证明每次实际读取 Skill 正文。
- 第十八、十九轮累计 `4对2` 是揭盲后的探索性风险汇总，不是预注册升版检验。
- 本复核只做决策，不改 Skill、活动用例、README、冻结标准或评分结果。
