# Claim quantitative confirmatory 13

这是 `claim-evidence-review` 0.1.0 的确认性定量保真评测。第十八、十九轮在五个相关题型、每臂15个输出中探索性观察到：0.1.0 有4次核心数字遗漏，baseline 有2次。该跨轮汇总是在揭盲后形成，只能触发本协议，不能直接证明退化或修改 Skill。

本轮使用三个全新合成表面：相同比例但样本量不同、分母更正与另一组分母缺失、严格短表中的两批前后值。无 Skill 与0.1.0使用相同的 `gpt-5.6-sol`、`medium`、任务正文和只读隔离环境；Skill 臂采用项目级显式调用。每题每臂重复五次，共30个独立输出，失败不重试。

本轮用于候选触发的“核心定量遗漏”只按下列指定标准计数，一份输出在同一题最多记一次遗漏：

- `equal-rate-different-denominators`：第二条；必须同时保留 `5/20` 与 `125/500`，并识别两者均为25%但样本量不同。
- `corrected-and-missing-denominators`：第一条；必须同时保留北区 `12/60 → 12/80`、当前15%，以及南区已知分子9、未知分母。
- `strict-table-two-batches`：第二条；必须同时保留甲批 `6/60 → 3/60` 和乙批 `20/200 → 15/200` 及其不同幅度；第二条允许用完整的等价百分比表达。

只有0.1.0在至少两个题型中各出现不少于 `2/5` 的核心定量遗漏，且 baseline 在这些同题型中各不超过 `1/5`，才打开0.1.1候选设计。门槛未达到时保持0.1.0；达到时也只授权设计候选，不能直接修改、升版或发布。跨第十八、十九轮的4比2不并入本轮门槛。

正式运行前由另一个同项目任务检查算术、来源依赖、核心遗漏计数、严格表格约束、两臂公平性和候选触发条件。协议冻结后先提交再运行。生成输出、盲评逐项判断、揭盲、门槛判定按顺序进行；揭盲后不修改题面、硬标准或计数方法。

本实验不测试隐式发现、联网核验、真实研究质量或独立人工领域评审。相同比例题不要求模型计算置信区间或显著性；表格题不要求复述与待审论断无关的响应时长和满意度。
