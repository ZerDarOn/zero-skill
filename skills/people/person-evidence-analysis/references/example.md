# 完整合成示例

此例只展示输出形状，人物与对话均为虚构。

## 输入

用户：我一直觉得 B 从不主动，你看看这段记录。

```text
m1，B：周六一起吃饭吗？
m2，A：这周忙，下次吧。
m3，B：好，你有空告诉我。
```

## 回答

就这段记录而言，“B 从不主动”与材料不符；它只能推翻这一次的绝对说法，不能证明 B 一直很主动或一定喜欢 A。

**可观察到的**

- `m1` 中 B 主动提出了具体邀约：“周六一起吃饭吗？”
- `m2` 中 A 没有接受本周邀约，只说“下次吧”。
- `m3` 中 B 接受了这次未能约成，并把下一次联系窗口留给 A。

**可能解释**

- 这一次互动里，B 是发起者；这是对“从不主动”的直接反证。
- `m3` 可能表示 B 尊重 A 的时间，也可能表示 B 暂时不再加压。单凭这句话无法区分两者。

**反证与其他解释**

- 用户的长期印象可能来自其他未提供的互动；当前三条消息不足以评价长期模式。
- 一次邀约也不能反向证明稳定好感，邀约目的和双方平时的互动仍未知。

**仍不知道的**

若要判断长期主动性，最有帮助的是一段较完整时间范围内双方各自发起话题、邀约及跟进的记录。
