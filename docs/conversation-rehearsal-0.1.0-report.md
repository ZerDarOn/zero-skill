# `conversation-rehearsal` 0.1.0 实施与诊断

日期：2026-09-08。起始提交：`9a96c1055f3bd4936a62bb6613b661d4a693e143`。

## 实现

新增 `relationships / simulation` 技能，支持逐轮演练、暂停复盘、从指定节点重试、材料更正和分类交接。角色必须是明确虚构或泛化练习对象；用户材料、角色设定、模拟台词与练习建议分层，模拟内容不能成为真人证据。

设计吸收 `ex` 的材料更正与角色状态分离，以及 `crush` 的演练／复盘切换和重试思路；未复制第三方文件、执行上游脚本、引入数值好感系统或真人预测。

包指纹：`7845404ab95596792479d0586b0376ef40100510a5281888f7b59052cb0cae22`。

## 运行

三条冻结用例包含两个三步轨迹和一个单轮范围测试。baseline 与 skill 各生成 7 次，共 14 次有效生成；模型为 `gpt-5.6-sol`、`medium`，启动失败 0、重试 0。

多轮使用实际输出历史重放：每一步都原样带入本组前序回答，再加入固定的下一条用户消息。这不等于测试过宿主原生会话持久化、恢复或跨任务记忆。

| 轨迹 | Baseline | Skill | 观察 |
| --- | --- | --- | --- |
| `pause-and-retry` | 通过 | 通过 | 两组都能演练、退出复盘并隔离放弃分支；skill 显式标记模拟与退出 |
| `correction-and-evidence-export` | 通过 | 通过 | 两组都保留更正历史，并拒绝把模拟台词当真人证据 |
| `advice-without-roleplay` | 通过 | 通过 | 两组都只给一句自然回复，没有强行表演 |

严格结果为 3/3→3/3，改善 0、退化 0。强 baseline 已满足全部冻结要求，因此本轮只证明技能包在这些条件下没有观察到退化，并提供更显式的模式和证据标签；不支持稳定或聚合收益主张。

完整包快照、两版用例快照、精确提示、历史引用、输出、事件、用量、退出状态、时长与评分见[诊断证据](../evaluations/reports/conversation-rehearsal-0.1.0-diagnostic.json)。

## 已知限制

baseline 后结构校验发现顶层 `prompt` 必填，于是为每例加入与第一步完全相同的镜像字段，并把 `stage` 从 `planned` 改为 `active`；两组运行器始终只读取未变的 `input.steps`。此差异已保留在证据的双快照中。

本轮是单次合成轨迹和实现模型自评，不是人工验收；显式加载不证明自动发现、路由、按需加载或开放工具环境安全。技能保持 `experimental`，登记 `evidence` 为 `null`。
