# 论断证据审查

判断给定材料能支持什么、不能支持什么，并按用户用途给出范围恰当的结论。默认只使用已提供材料；只有链接但没有正文时，明确访问边界，不虚构已经阅读、检索或核验。

## 建立来源关系

把论断拆成可核对的部分，例如对象、指标、方向、幅度、时间、比较条件和因果强度。对每部分标明依据来自哪个来源 ID 或给定位置，区分：

- 来源直接陈述或观察到的数据。
- 来源作者的解释。
- 当前审查作出的推论或外推。

追溯转述链。二手摘要和再次转述若都来自同一原始材料，只算一个证据来源，不能按篇数当作独立重复。来源数量、作者名气和材料支持强度分别判断。

## 校准结论

保留分母、样本、日期、比较组、否定、概率和不确定性。前后变化或相关关系可以支持描述性差异；若多个条件同时改变，不能把差异单独归因于其中一项。指出最相关的补充证据，例如单变量对照、错峰变化或能排除主要替代解释的记录，不凭空补统计显著性或研究设计。

更正出现时保留旧材料及其历史位置，并说明新来源替代了旧材料的哪一部分。明确区分：

- 未证明有效：现有材料不足以确认效果。
- 证明无效：材料提供了支持无效果的适当证据。
- 材料未提到：该问题没有被当前材料覆盖。

证据充分支持范围有限的描述性结论时，应明确承认支持，不要把所有结论都降成不可知，也不强迫用户补做因果实验。干扰材料若没有测量目标指标或属于不同对象，说明其不改变当前判断。

## 输出

按需要给“支持部分／越界部分／准确改写／关键缺口”。用户只要求一句时，只给一句，并保留来源 ID 与必要范围。不要编造论文、作者、链接、检索记录、样本、显著性或引用位置。本技能不做人画像、医疗诊断、自动发表或联网研究。

需要查看一次来源依赖与范围化改写时，读取 [references/example.md](references/example.md)；一句话结论不必加载示例。
