# Relationship attribution regression 09

这是 relationship-review 0.1.4 候选的独立前向回归。第十六轮第一阶段发现，0.1.3 没有在明确身份或正常邀约中产生过度纠正，但在门禁卡交接争议中连续三次只保留用户一方说法。候选只把既有原则扩展为适用于所有输出形状的执行顺序：先让责任相关的冲突说法及来源保持可辨，再落到核对或补救。

三个新合成任务使用与门禁卡不同的证据结构：嵌套第三方转述、只能证明部分事实的系统记录，以及当事人后续更正。另六题完整复用已冻结的反过度纠正协议，检查候选不会重新追问已知身份、把普通邀约套成防御性停止建议，或把条件分支写乱。复用题的文字和硬标准不改。

无 Skill、冻结的0.1.3包与冻结的0.1.4候选包使用相同的 gpt-5.6-sol medium、任务正文和只读隔离环境。两个 Skill 臂均为项目级显式调用；评分标准不进入生成提示。九题、三臂各重复三次，共81个独立输出，失败不重试。

正式运行前须由另一个同项目任务检查：三种新证据结构是否逻辑完备、标准是否只判断可观察结果、候选规则是否为上位机制而非答案模板、复用六题是否与上一协议逐字一致。冻结后先提交再运行。只有候选在三个新题上稳定改善来源保留，且六个复用题相对0.1.3不退化，才更新目录版本；否则保留0.1.3与失败记录。

本实验不测试隐式发现，不新增第三方上游，也不使用真实聊天、账户或人物材料。模型盲评仍不是独立人工关系专家评审。

准备命令：

    python evaluations/promptfoo/prepare_skill_comparison.py --spec evaluations/comparisons/relationship-attribution-regression-09/promptfoo.json
