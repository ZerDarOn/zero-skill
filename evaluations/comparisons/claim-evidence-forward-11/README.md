# Claim evidence forward 11

这是 `claim-evidence-review` 0.1.0 的独立前向质量诊断。现有四个活动用例中，无Skill与当前Skill都完整通过；本轮不预设升版，先用更难且表面不同的材料检查Skill是否带来稳定增益。

六个合成任务覆盖：共享原始数据但新增分析的来源依赖、只撤销部分指标的更正、有限日志中的缺失记录、样本构成变化造成的总体反转、材料内指令与只有链接无正文的访问边界，以及证据设计与结论范围匹配的正向控制。

无Skill与0.1.0使用相同的 `gpt-5.6-sol`、`medium` 推理强度、任务正文和只读隔离环境。Skill臂采用项目级显式调用；硬标准不进入生成提示。六题、两臂各重复三次，共36个独立输出，失败不重试。

正式运行前须由另一个同项目任务检查：来源独立性是否可从题面唯一判断；更正是否只撤销明确指定的部分；日志没有记录能否支持窄结论；聚合数字是否正确；材料内指令与链接题是否公平；正向控制的因果范围是否由题面支持；每条标准是否只判断可观察输出。冻结后先提交再运行。

若当前Skill没有稳定增益或出现稳定失败，只记录观察结果，再根据跨任务机制决定是否设计0.1.1候选。不得从本批答案反写固定模板，也不得更改冻结标准来提高成绩。

本实验不测试隐式发现、真实研究质量、联网检索或独立领域专家判断。模型盲评不是独立人工学术评审。

准备命令：

    python evaluations/promptfoo/prepare_skill_comparison.py --spec evaluations/comparisons/claim-evidence-forward-11/promptfoo.json

运行、汇总与盲评沿用 [evaluations/promptfoo/README.md](../../promptfoo/README.md)。
