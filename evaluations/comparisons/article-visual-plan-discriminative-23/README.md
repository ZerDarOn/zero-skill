# Article visual plan discriminative 23

第二十九轮的六个明确文本规划题中，无 Skill、`article-visual-plan` 0.1.0 与固定 Baoyu 上游均为 72/72，无法估计相对帮助。本轮用新的任务表面降低题面提示强度，同时保持唯一评分依据，检查后续更正、证据兼容的视觉编码和复合计划编辑。

本轮仍只比较三者共同覆盖的文本规划子任务。Baoyu 上游完整流程包含偏好配置、确认、生图、写盘与文章回填，这些步骤统一跳过；结果不能外推为完整产品排名。固定提交、原始许可证、逐文件哈希和已知源链接问题沿用 `evaluations/fixtures/upstreams/baoyu-skills/6b7a2e417500561a5ecdd0b168332f4142584617/`，不安装或执行上游代码。

## 六个前向任务

- `source-revision-control`：后续审计撤回早期 43% 与因果说法；结尾负责人更正旧培训页中的自动批准流程。
- `evidence-compatible-encoding`：不同周次、样本和入选条件下的观察比例；没有确切主题频次且提问不同的定性访谈。
- `compound-plan-state`：一次全局风格变化与一次局部流程更正；同时删除旧项和插入固定新项并保留非连续 ID。

任务材料不复用第二十九轮六题。公共提示只规定一次性文本规划与执行边界，不提示来源优先级、应选图形或计划变更结果；这些要求来自各题材料，硬标准不进入待测提示。

## 规模与盲评

三臂使用相同的 `gpt-5.6-sol`、`medium`、只读隔离环境、公共提示和任务正文；两个 Skill 臂采用项目级显式调用。每题每臂重复三次，共 `6 × 3 × 3 = 54` 份输出、18 个三候选匿名评阅项和 216 个布尔判断。失败保留且不重试。

评阅者逐项判断四项硬标准并记录偏好；不能用总体印象覆盖标准，也不能根据 Skill 身份改分。评分锁定后才读取独立映射。模型辅助评阅不等于独立人工视觉设计评审。

## 冻结候选门槛

本地改版门槛只比较 ours 与 baseline。对某一机制的两道题，若 ours 在每题都至少 `2/3` 次出现核心失败，同时 baseline 在每题最多 `1/3` 次核心失败，且 54 份输出全部满足运行有效性门禁，才打开最小候选设计。一次输出只要该题任一 `core_criteria` 为假即计为核心失败。upstream 只提供设计上下文，不进入门槛。

门槛只授权候选设计，不直接修改 Skill、升版或发布。单题失败、跨机制各失败一题、两臂共同失败、非核心标准差异、偏好差异或上游优劣都不能触发。冻结后不得改题、改标准或补跑失败来改变结论。

## 边界

本轮不测试隐式路由、实际图片质量、文字渲染、文件落盘、生成后端、编辑器集成或真实读者理解。只读任务不需要命令执行；任何可观察的命令、文件、MCP、网页搜索或 Codex app 调用都会使运行无效。当前通用 Promptfoo 结果仍不能观察 provider item 形成前的宿主拒绝，因此不宣称覆盖不可观察的预路由工具失败。
