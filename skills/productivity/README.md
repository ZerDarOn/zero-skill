# 办公与效率

范围：文档、表格、会议与知识管理。

当前有三个 `experimental` 技能：`obsidian-note-edit` 0.1.0 用于整理或窄范围编辑给定的 Obsidian Markdown；`product-context-brief` 0.1.0 用于把产品、角色、证据、计划和未知项整理成可复用背景；`meeting-communication-review` 0.1.0 用于根据给定转录和统计材料复盘可观察的会议沟通行为。三者都不自动扫描、安装、联网、转录或发送反馈。

新增包和登记方式见 [贡献指南](../../CONTRIBUTING.md)。分类及已收录技能以 [登记表](../../catalog/collection.json) 为准。
