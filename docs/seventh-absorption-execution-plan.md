## A：学习与练习计划

依据目标、截止点、明确可用时间、内容范围、先修关系和已有表现安排可执行练习。信息够用就先给方案；非关键缺口标假设，不强制问卷。任务中的现实考试大纲、报名或考试规则若需要核验，应另查权威来源；不可从合成课程推及真实认证要求。

各时段总安排不得超过容量，不挪用明确不可用的日期，不把已完成内容重做一遍当作调整。把阅读、回忆/练习、反馈纠错和必要休息纳入同一时间预算；不隐去练习成本以凑“全部覆盖”。时间不足时说明缩减与遗留内容；不保证通过考试或持久记忆。

优先次序结合明确的重要性、先修条件、练习表现和不确定性。只有自评时可以用作初始线索，但不把自信当成掌握。复习间隔根据日程可行性设置，不宣称某个固定间隔普遍最佳。后续更新保留已完成事实，只重排剩余容量；调整理由连接新输入。

四个合成用例方向：

1. `fit-the-available-slots`：给不等长可用时段、明确不可用日期与需先后学习的两个主题，要求逐时段计划。练习和反馈计入容量，先修关系不倒置；多种合理分配都接受。输入明确学习截止点与各任务最低必要时间，避免评审暗加“每次至少45分钟”。
2. `confidence-versus-performance`：某主题自评高但实际练习错误明显，另一主题自评低但已给练习表现好，另给主题重要性。请求分配有限练习时间；应考虑实际证据，不能只按自信高低机械分配。不要强制精确倍数或唯一比例，也不要求把一次高分当永久掌握。
3. `replan-without-rewriting-history`：给已完成、遗漏和未来可用时段的旧计划，新增时间冲突，要求只调整剩余部分。保持完成历史，不把遗漏标已完成，不安排冲突时段；接受合理取舍和在剩余容量内的不同顺序。
4. `compressed-plan-with-tradeoffs`：剩余容量小于全部内容最低需求，用户要求在限制内给压缩计划并说明取舍。显式承认不能全覆盖，按已给重要性/先修条件选择，并留练习与纠错；不借“以后再补”伪装截止前已覆盖。

用例以分钟/相对日期或完全明确的日期窗口表达，给足总容量、先修与任务需求；不评估真实学习提升或考试通过率。避免让自评与小样本练习之一成为绝对真值。

## B：漫画分镜起草

按用户给的读者、核心内容、格数/页数和文本限制，写出可供后续绘制的分镜。每格有可画的场景或动作，文字与画面一致，阅读顺序清楚；同一角色、道具、位置和状态跨格保持连续，变化有动作或说明支撑。

分清真实资料、旁白解释、虚构角色与创作台词。允许创意，但不能把模拟对白写成真实人物原话，也不能为戏剧效果改动资料的条件、范围或因果。知识类比应帮助理解，并保留题材中容易误导的关键差异；不要求每篇都附长免责声明。

材料充分时直接产出，不把人物设定表、封面、风格问卷或生图提示强加给只要几格脚本的用户。无对白可用动作、符号与指定允许的文字；格内文本要求按用户定义执行，不把画外制作说明混为图内文字。只改指定格时保留其他格并检查前后衔接，不借优化重写全篇。

此技能交付分镜文本；没有实际生成图片、观察成图或做读者测试就不能声称完成这些步骤。不得因上游会生图就自动调用生成后端、开销付费额度、建立配置或发布作品。

四个合成用例方向：

1. `continuous-four-panel-action`：明确人物、道具初始位置、动作目标，要求恰好四格可绘制分镜。检查连续变化与结尾目标，不按唯一镜头语言判分；不强制角色设定表或封面。
2. `metaphor-keeps-the-rule`：提供自包含的知识材料和一个容易过度类推的视觉比喻，要求短漫画。保留材料的关键条件，不让画面/对白宣称被材料排除的结论；允许放弃不合适比喻或修正它，不能强制选某一形象。
3. `fiction-is-not-a-quote`：给一位明确合成人物的简短事迹，没有逐字原话，请求改编分镜。可以明示创作对白或用旁白，不得标为人物真实原话或添加虚构来源；避免真实人物资料。
4. `revise-one-silent-panel`：给完整三格无对白草稿，用户只修改第二格动作，使其与固定第一/三格相接；限制指向图内文字，制作说明可写。只返回修订第二格，保持衔接与无对白边界，不重写两侧格或加入对话泡。

格数、图内/图外文字、仅改范围须在 prompt 明确；不得隐藏要求某句免责声明、某个镜头、固定道具颜色。核心评分检查叙事连贯、材料准确与任务完成，格式另列；不把文本分镜通过写成成图视觉质量已验证。
