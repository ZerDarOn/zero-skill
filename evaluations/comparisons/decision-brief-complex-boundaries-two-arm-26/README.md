# 当前决策简报复杂边界两臂前向比较

本轮比较无 Skill 与 `decision-brief-draft` 0.1.1。当前版只有六个活动合成用例；0.1.0 到 0.1.1 的两个新增题均通过，尚未观察到版本增益。本轮只用六个未参与当前 Skill 编写的新表面，检查复杂材料中的决策历史、硬约束与比较口径，以及角色权限与有限证据。

## 固定设计

两臂使用同一个 `gpt-5.6-sol`、medium、只读隔离配置、公共提示与任务正文。Skill 臂采用项目级显式调用。每题每臂重复三次，共 `6 × 2 × 3 = 36` 份输出、18 个双候选匿名评阅项和 144 个布尔判断。失败保留且不重试。

六题按三个机制各两题组织：

- `decision-history`：新的无障碍资格消除原批准依据的独有性，但不产生新批准；成本更正不撤销基于未变硬约束的既有批准。
- `constraint-and-denominator`：一次性与年费必须归一到三年口径；一个选项违反硬约束、另一个关键指标未知时不能强行选。
- `role-and-evidence`：高管偏好与工作组建议不等于有权机构批准；小规模可用性完成数、无现流程对照和未测生产底线不能支持全量推广。

每题四项硬标准，前三项是核心标准。候选门槛要求同一机制的两题都出现当前 Skill 至少 `2/3` 次核心失败，同时 baseline 每题最多 `1/3` 次核心失败，且 36 份输出全部有效。满足门槛只允许打开最小候选设计，不直接改 Skill、升版或改变 catalog。

匿名评阅按语义满足程度判断，不要求逐字复述；只能使用冻结题面支持的事实与预先写入的硬标准，不得揭盲后增加要求。偏好与逐项硬标准分开记录，偏好不改变布尔判断。

## 上游边界

`decision-brief-draft` 的设计曾参考 Anthropic `doc-coauthoring` 的读者视角与有界协作方法，以及 Witchcat 的决策记录方法。两者都不是与本地技能等价的单轮决策简报产品：前者是更长的协作写作流程，后者嵌在工程工作流且仓库没有统一许可证。本轮不组装或运行它们，避免把流程范围差异当成回答质量差异；它们继续作为设计来源，不作为计分 arm。

本轮只测试合成、单轮、中文、显式调用和文本返回，不验证真实审批系统、文档写入、多人协作、隐式路由或决策效果。
