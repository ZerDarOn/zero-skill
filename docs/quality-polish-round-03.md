# 第三轮质量打磨：人物分析的来源、指代与更正

日期：2026-09-10。基准提交：`1e01de48f84231b00afda4f5ba3effb5d946dbf3`。本轮只修改人物证据分析，最终版本为 **0.1.2**；16 个技能继续保持 `experimental`，没有新增上游收录。

## 改动及实际发现

先做 0.1.1 候选，明确两条规则：多份转述若来自同一事件，不能累计为独立行为证据；发言人等材料被更正或更正被撤回时，更新受影响判断，用户只要最终一句时不强制展示完整历史。

旧版 0.1.0 已能通过这三个新增案例，因此这两项是规则精度改进，不能宣传成修复了旧版已观察到的失败。

候选版完整回归时发现具体问题：原有 `contradiction` 案例没有说明“她”指 A 还是 B，回答却先说“她从不主动”与记录矛盾，到后面才补“如果她指 B”。这使首句判断超出了已知目标范围；旧冻结标准只检查 B 主动这一反证和不过度推断，未覆盖条件出现的位置，故保留冻结成绩并单列发现。

最终 0.1.2 补充：模糊指代先限定对象或条件分析，再下结论；简单问题默认用短段呈现关键观察和限度，不机械设置完整报告标题。同题复测先分别说明 A/B 两种情况，再判断各自行为。另增加一个模糊指代案例：最终回答以“如果她指乙”限定范围，没有擅自确定对象，也没有把乙本周排不开解释成完全不愿推进。

共 **33 次有效生成**，没有失败重试或排除。一个三步轨迹按一个案例评分，所以生成数大于案例数。每一步通过新的 CLI 调用回放该组此前的精确用户消息和模型回答；后续纠正消息不提前提供。它验证带历史的回答，不代表已经验证宿主持久会话或自动加载。

无技能唯一未通过项是连续更正轨迹的第二步没有说明“发言人标注更正”这一依据；三次当前发起者都正确，句数也符合要求。按核心状态跟踪和任务理解计，无技能为 7/7。因此 6/7→7/7 主要是依据交代完整性，不能解释成人物理解能力提高。

三个初始新案例的旧版到最终版均为 3/3，没有通过数增益。最后新增案例没有无技能或旧版配对，不能将最终 8/8 与无技能 6/7直接作为同一分母比较。
