# 第二十二轮质量打磨：故障证据边界前向诊断

本轮用七个未参与 `debug-evidence-triage` 0.1.1 编写的合成故障题，复测它在材料不完整时能否保持证据链、验证等价性和副作用安全边界。协议先在提交 `c77052ac93bcae3e7fa76d48dda3ab49b6fbb923` 冻结；两臂使用相同的 `gpt-5.6-sol`、`medium`、只读隔离环境和任务正文，当前包只通过项目级显式 Skill 调用。每题每臂重复三次，共 42 份有效输出、21 个匿名配对和 168 个逐项布尔判断。

## 结果

原始匿名评阅近似持平：无 Skill 为 `68/84`、`11/21` 份完整，当前 0.1.1 为 `69/84`、`11/21` 份完整；两臂各获 3 次偏好，另有 15 次持平。全部 42 份输出有效，没有 provider error 或禁止工具记录。

计分后独立复核发现一个明确的语义判分错误：超时幂等题的六份回答都用条件分支表达了“事务最终状态未明时不得重放”和“必须证明当前版本实际持久化、命中幂等键或有等价原子防重”，原匿名评阅却因没有机械复述固定句式而把核心项全部判为失败。公开报告保留原布尔和 notes，并另列六项 `false → true` 校准；不回写运行产物，也不重算偏好。校准后无 Skill 为 `71/84`、`13/21` 完整，当前包为 `72/84`、`13/21` 完整。

| 机制 | 原始核心错误（无 Skill / 当前包） | 校准后 | 候选门槛 |
| --- | --- | --- | --- |
| 证据链 | clock `0/0`；ordered `0/0` | 不变 | 未触发 |
| 验证等价性 | control `0/0`；quiet `0/0` | 不变 | 未触发 |
| 副作用安全 | timeout `3/3`；GET `0/0` | timeout `0/0`；GET `0/0` | 两种口径均未触发 |
| 决定性复现控制 | substring `0/0` | 不变 | 诊断题，不参与 |

冻结门槛要求同一合格机制的两道不同题都出现当前包至少 `2/3` 核心错误，并且 baseline 在每道对应题均不超过 `1/3`。原始口径中 timeout 是两臂共同失败，而且同组 GET 为 `0/3`；校准后全部七题两臂核心错误都是 `0/3`。因此两种口径都不能打开 0.1.2 候选设计。

## 质量判断

当前包在七个核心判断上没有观察到稳定退化，也没有相对 baseline 的可重复核心收益。总分与偏好近似持平，说明现阶段没有证据支持继续堆叠指令。0.1.1 保持不变，状态仍为 `experimental`，`evidence` 仍为空；七个冻结题全部加入活动回归，故障证据排查从 6 例增至 13 例，全仓活动用例从 125 增至 132 例。

当前包的代价更高：总 token 从 209,450 增至 231,822，约增加 10.7%；prompt token 增加 10.9%，completion token 增加 5.0%，记录成本增加 21.7%，中位延迟增加 25.3%。这些数字来自本轮相同配置，不应外推为一般成本规律。

部分非核心扣分测量的是冻结方法契合度。例如 GET read-repair 题要求隔离合成记录的运行复现；选择安全的静态路由或调用链检查仍会在对应标准上失败，但这不等于没有识别写副作用。报告同时保存逐题结果和这个解释边界，避免把总 hard 分误称为一般诊断正确率。

## 证据完整性

匿名评阅者只读取随机化候选包与空白表单，未接触映射键、协议或当前 Skill，且报告记录了任务名、模型、推理等级、允许文件和空的意外读取列表。另一名独立子代理在揭盲后做语义校准；它看过协议和当前 Skill，因此明确标为非盲复核。

自包含机器报告绑定冻结提交、模型配置、Skill 包指纹、协议与准备文件哈希、八份运行产物哈希、两位评阅者元数据、计分后复核文件、42 份完整输出、原始与校准布尔以及偏好。测试会分别复算两套总分、逐题核心错误和候选门槛，并对原始分数、校准分数、输出、产物哈希和评阅者披露做负向篡改检查。

## 限制

本轮只覆盖合成材料、单一模型、单一推理等级和显式 Skill 调用。两位评阅者都是模型辅助独立子代理，并非独立人类；语义校准者也不是盲评者。结果没有测试隐式路由、真实生产事故、工具自主执行、部署权限、其他模型或最终修复效果，不能支持 `verified` 状态或普遍优越性结论。
