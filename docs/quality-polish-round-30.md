# 第三十轮质量打磨：文章配图规划鉴别性前向盲测

日期：2026-09-13

## 本轮问题

第二十九轮的六个明确文本规划题中，无 Skill、`article-visual-plan` 0.1.0 与固定 Baoyu 上游均为 72/72，出现天花板效应。本轮改用六个更难、但仍可唯一评分的合成任务，减少题面中的解题提示，检查后续来源更正、证据与视觉编码的一致性，以及复合计划编辑时的状态保持。

比较范围仍是三者共同覆盖的单轮文本规划。Baoyu 上游包含偏好确认、生图、写盘和文章回填等完整流程；这些步骤没有运行，本轮结果不能用作完整产品排名。

## 固定设计

协议、六题、完整配置与上游夹具在提交 `b5b45539fe9b7adddf2ca2199ab6c6011cf8461d` 冻结并推送。三臂使用同一个 `gpt-5.6-sol`、medium、公共提示与只读隔离配置；每题每臂重复三次，共 `6 × 3 × 3 = 54` 份输出、18 个匿名评阅项和 216 个布尔判断。失败保留且不重试。

六题按三个机制各两题组织：

- `source-revision-control`：审计撤回早期指标与因果说法；负责人更正旧培训页中的自动批准流程。
- `evidence-compatible-encoding`：对样本与入选条件不同的观察比例采用公平并列结构；定性访谈没有频次时不制造强度差异。
- `compound-plan-state`：全局风格变化与局部内容更正同时发生；删除旧项并插入固定新项时保留稳定 ID。

每题四项硬标准。候选门槛在运行前写定：同一机制的两题中，当前 Skill 必须每题至少 `2/3` 次出现核心失败，同时 baseline 每题最多 `1/3` 次核心失败，且 54 份输出全部有效，才允许打开最小候选设计。上游只提供设计参照，不参与本地改版门槛。

冻结前独立复核发现两项 P2：异组比例题最初把位置和编码写得过窄；测试也没有锁定完整配置与拼接后的提示。前者改为要求明确位置与公平的并排、等权卡片或等价结构，后者加入完整文件哈希、公共提示、三臂字段和实际提示拼接断言。修订后复核无 P0–P3，才冻结并运行。

## 正式结果

预检 3/3 完成且只验证基础设施，不计分。正式运行 54/54 完成，三个臂各 18 行；provider error、禁止工具轨迹和 Promptfoo 失败均为 0。

| arm | 完整通过 | 标准通过 | 唯一偏好 |
| --- | ---: | ---: | ---: |
| 无 Skill | 16/18 | 70/72 | 0 |
| `article-visual-plan` | 16/18 | 70/72 | 0 |
| `baoyu-article-illustrator` | 16/18 | 70/72 | 0 |

18 个评阅项全部没有唯一偏好。六个 `false` 判断中，五个来自 `owner-corrected-human-review-flow`：答案在正确表达人工复核与负责人更正之外，又补了材料未要求的“重新提交”。该项属于非核心边界，三臂均出现，分布为 baseline 一次、当前包两次、上游两次。

唯一核心失败出现在当前包的 `unequal-cohort-observed-rates` 第三次重复：答案保留了 `12/20` 与 `14/18`，但没有明确写出 `60%` 与约 `77.8%`。同机制的另一题没有核心失败，且该题当前包只有 `1/3` 次失败，因此没有达到预注册候选门槛。揭盲后独立复核保留全部六个判断，没有改分，也没有发现 P0–P3 问题。

## 鉴别力与成本

更难的题目打破了全满分，但三臂汇总仍完全同分，且唯一核心失败是当前包的一次孤立遗漏。这组证据没有显示当前 Skill 相对 baseline 或上游的净收益，也没有形成可归因于 Skill 的重复退化机制。

当前 Skill 相对 baseline 的总 token 多 `9.7%`、记录成本多 `22.8%`，中位延迟少 `5.8%`。上游相对 baseline 的总 token 多 `43.4%`、记录成本多 `95.2%`，中位延迟多 `3.0%`。当前 Skill 相对上游少 `23.6%` token、少 `37.1%` 记录成本，中位延迟少 `8.6%`。这些数字只描述本次 Promptfoo 记录，会受输出长度、缓存、定价和调度影响，不是稳定性能基准。

## 技能与仓库决定

`article-visual-plan` 正文、版本和 catalog 均不变，继续是 0.1.0、`experimental`、`evidence: null`。包指纹仍为 `e02fed142a73421a2cc091bfea0d6faefef4c8035e671d4866e65708e9973a87`。

六个冻结前向题加入活动回归，该 Skill 从 10 例增至 16 例，全仓从 154 例增至 160 例。公开机器报告保存 54 份合成输出、匿名评分投影、运行汇总、来源与产物哈希、门槛及限制；本机存在被忽略的原始 Promptfoo 产物时，测试会按哈希重建语义投影。公开报告还用固定投影与协调变异测试防止报告和测试被一起改写后静默漂移。

本轮评阅者是模型辅助的独立任务，只对随机臂映射保持盲态，并非独立人工视觉设计评审。评测没有覆盖隐式路由、实际生图、文字渲染、文件回填、编辑器集成或真实读者理解。原始 Promptfoo 产物仍被 Git 忽略，新克隆只能核验公开报告中的合成输出和哈希，不能重建 provider 事件。

## 下一步

同一 Skill 已连续完成两轮三方前向评测。继续追加相近文本题的边际价值较低，下一轮应转向其他尚缺严格前向证据的技能；文章配图规划保留这 16 题作回归。只有在具备安全的制品环境与可审查图片时，再单独设计实际生图、渲染和文件集成评测。
