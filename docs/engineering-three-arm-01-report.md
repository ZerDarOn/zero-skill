## 保留的超时与额外诊断

上游memo第二次实验E10的新增测试在取消等待者后执行：

```python
release.set()
await completed.wait()
```

修复后底层查询仍继续，会设置completed，因此该测试通过。原始实现会把底层查询取消，completed永远不会设置。整套原版回归在第一项测试挂住，被运行器的15秒上限终止，记录为超时、0项完整结束，**没有把超时当成一次有效失败断言**。

这个风险在实际挑战和分组揭示前就已记录。之后保留全部原记录、不修改候选，单独执行剩余三项测试：其中两项在原版分别暴露失败缓存和底层取消后不可重试的问题，修复版三项都通过。因此可确认该文件含有效回归，但它在坏代码上正常结束的能力仍有缺陷。

上述六次逐项测试属于明确标注的事后诊断，不增加模型回合，不替换主试验结果。改进方向是给等待设置合理上限，并保证失败路径能回收挂起任务；本轮为保留原始对照，没有修改候选或技能。
